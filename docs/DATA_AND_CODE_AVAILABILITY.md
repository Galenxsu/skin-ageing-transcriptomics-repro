Public data used in this study are available under GEO accessions GSE85358, GSE18876, GSE130973 and GSE70138. This repository contains the analysis scripts, frozen decision rules, compact public-release inputs, environment specifications and SHA-256 manifests needed to audit the reported workflow.

The large GSE70138 Level-5 matrix and the derived null/checkpoint arrays are not redistributed. The source matrix should be obtained from GEO and checked against `manifests/LARGE_ASSET_SHA256.csv`; null arrays and checkpoints are derived computational assets and should be regenerated with the released scripts, frozen seeds and iteration counts. No reduction of the null family is permitted for a confirmatory reproduction.

The full Phase 171B workflow was reproduced in an author-controlled isolated workspace. All 2,999,987 planned null permutations completed, the independent implementation validation completed 99,999 permutations and passed, and the principal result files matched their frozen counterparts by SHA-256. This is not described as independent third-party validation.
