# 可直接纳入补充方法的中文方法学闭合稿

## 研究设计与分析边界
本研究采用分阶段、规则冻结的二次分析框架。年龄组相关转录特征首先在GSE85358的48份成人女性前臂表皮样本中估计；随后通过预先固定的预处理与模型敏感性分支评价结果对技术选择的稳定性，并结合冻结的组织和单细胞证据对基因及通路进行分层。化合物部分使用GSE70138 Level 5扰动表达资源，在结构身份可解析的有限化合物母集中进行探索性反转筛选。发现集与资源内部留出集按基础细胞系分离。所有评分、随机化、多重检验和分类规则均在读取相应扰动表达值或查看候选结果前冻结。该设计不构成外部实验验证。

## GSE85358预处理和差异分析
主流程P2纳入非控制探针，以Agilent gMedianSignal和gBGMedianSignal为前景与背景输入，使用limma的normexp方法（offset=50）进行背景校正，随后log2转换并实施分位数标准化。具有相同ProbeName的重复点在标准化log2尺度取均值。基因层分析仅采用Phase 131已冻结的一对一HGNC代表探针；若冻结代表探针在某分支中缺失，不以其他探针补位。主模型使用limma线性模型和经验贝叶斯收缩，设计矩阵为~age_group，以young为参照，效应方向定义为old−young。BH法在11,412个基因内控制FDR，主发现阈值为BH-FDR<0.05。主模型保留全部48名供者。扫描日期、ArrayName和arrayWeights模型分别作为敏感性分析；未应用ComBat或SVA。

## 基因证据等级
内部稳健性要求基因在P2/M0、P2/M1、P2/M2、P2/M3、P1/M0和P3/M0六个固定分支中均可评价、logFC方向一致，且各分支按|moderated t|计算的百分位跨度不超过0.20。Tier A定义为主模型BH-FDR<0.05、满足内部稳健性且具有符合冻结供者覆盖和方向条件的角质形成细胞单细胞支持；Tier B定义为主模型BH-FDR<0.05且满足内部稳健性、但不具备Tier A所需的单细胞方向支持；Tier C定义为主模型BH-FDR<0.05但不满足内部稳健性。成纤维细胞轴不参与上述等级判定。

## LINCS有限母集和查询
扰动筛选限定于GSE70138 Level 5资源中身份与结构规则合格的1,792个pert_id、107,201条签名以及与表皮测试空间一对一映射的8,227个基因。主查询G2_R2_CAP8使用主表皮模型的有符号moderated t，在绝对值8处截断后于8,227基因空间内L2归一化。发现集与留出集使用互不重叠的基础细胞系；distil_id泄漏检查为通过。正常成人皮肤精确匹配情境为0，因此所有结果均限定为跨情境探索性扰动线索。

## 评分、聚合和null
每条profile的连接分数为扰动表达向量与年龄权重向量的余弦相似度；负值表示反转，正值表示拟态。聚合顺序固定为：同一compound×cell×dose×time内profile取中位数；同一基础细胞内各context取中位数；同一fold内各基础细胞再取中位数。未按结果选择最佳剂量、时间或细胞。competitive null在冻结的测量类别×表皮平均表达五分位共15个层内匹配抽样，使用NumPy Generator(PCG64)及查询特异种子。下尾反转P=(1+Σ[null≤observed])/(B+1)，上尾拟态P=(1+Σ[null≥observed])/(B+1)。主分析及敏感性共完成2,999,987次有效随机化。

## 多重检验、支持门和分类
BH校正在12个冻结的完整方向性检验家族内分别实施，共53,760个方向性槽位；不可评价槽位仅为保持家族规模而以P=1进入校正。主发现和内部留出反转均要求聚合分数<0且BH-FDR<0.05。最高统计等级还要求至少两个基础细胞支持、profile/context最低数量门、leave-one-context/cell/dose/time稳定、HQ子集可评价且方向一致、低剂量敏感性通过、数值无效比例不超过冻结上限、结构身份明确、表示方式稳定，且不属于历史暴露的6种化合物。分类优先顺序及全部降级理由由代码机械计算；没有依据名称、中药来源或生物学合理性人工调整。A类表示具有资源内部留出支持的探索性反转候选，不等同于正常皮肤验证或抗衰老药物。

## 数值复核与结果冻结
关键连续值以float64计算。两条独立实现使用atol=1×10^-12和rtol=1×10^-10比较连续值；成员、ID、分组、计数、随机种子、null极端值计数、检验家族、方向、显著性判断、分类和降级理由要求精确一致。任何阈值两侧不一致或方向不一致均触发停止。主null及关键候选独立复核通过。后续Excel恢复仅修复UTC时间戳的文本序列化，冻结统计结果未改变。
