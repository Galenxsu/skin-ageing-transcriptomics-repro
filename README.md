# Skin ageing transcriptomics reproducibility package

Release: `v1.0.0-p0-repro`; archive target: Zenodo.

This repository preserves the code, frozen rules, compact inputs and audit evidence for the GSE85358 epidermal age-group analysis and GSE70138 limited-universe perturbation screening. The eight statistical class-A compounds are exploratory candidates with resource-internal held-out support, not validated anti-ageing drugs.

## Reproducibility status

- **Verified in an author-controlled isolated workspace:** the complete Phase 171B null analysis (2,999,987/2,999,987 permutations), an independent implementation check (99,999/99,999 permutations; PASS), post-processing and result-identity checks.
- **Result identity:** the clean-room CSV outputs matched the frozen outputs by SHA-256 for the core statistics, classification, discovery, held-out and comparison tables.
- **Workbook validation:** 27 generated workbooks passed cell-level readback after a format-only repair of three ISO-8601 timestamp cells; scientific values and classifications were unchanged.
- **Interpretation boundary:** this is reproduction within the authors' working environment, not independent third-party validation.
- **Not bundled:** the large GSE70138 matrix, derived null arrays and checkpoints. Obtain the source matrix from GEO and verify the hashes in `manifests/LARGE_ASSET_SHA256.csv`; derived arrays are regenerated by the frozen workflow.

## Layout

- `data/frozen_phase171a/`: minimal public-release input bundle and release manifest.
- `data/historical_phase170b/`: compact historical comparison inputs.
- `src/phase171b/`: complete Phase 171B scientific scripts.
- `src/historical/`: immutable historical snapshots retained for provenance.
- `validation/`: clean-room completion and result-identity evidence.
- `docs/`: method, availability, runtime and transformation notes.

## Running

Install the pinned Python dependencies, obtain the GSE70138 Level-5 GCTX asset, and run:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_cleanroom_pre_expression.ps1 `
  -WorkDir C:\path\to\phase171b-work `
  -GctxPath C:\path\to\GSE70138_Level5.gctx `
  -Python python
```

The runner invokes `scripts/preflight.py`, which refuses to proceed below 60 GiB free disk. It does not reduce permutation counts or change seeds. The full null stage is deliberately not launched automatically by the pre-expression runner because it is computationally intensive; the frozen query counts and seeds remain in the released registry and scripts.

Historical snapshots may contain workflow-era conventions but no author email or local absolute path is included in this release. See `docs/DATA_AND_CODE_AVAILABILITY.md` and `docs/CLEANROOM_RUNTIME.md`.
